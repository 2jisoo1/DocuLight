🧪 DocLight Auto-Load Feature Test Suite

📋 Test Overview

This test suite verifies the auto-load functionality with IndexedDB implementation.

Test Objective: Ensure that when a user refreshes the page, the last viewed file is automatically loaded with its parent folders expanded.

🔧 Prerequisites

  • ✅ Server running at http://localhost:3000
  • ✅ Browser with IndexedDB support (Chrome, Firefox, Edge, Safari)
  • ✅ Test file: guide/programming-samples.md exists in docs directory

📝 Manual Test Steps

1 Navigate to Application

Open http://localhost:3000 in your browser

Expected: Welcome screen displayed, no file loaded
2 Expand Guide Folder

Click on the "guide" folder in the file tree to expand it

Expected: Guide folder expands, showing child files including "programming-samples.md"
3 Load Test File

Click on "programming-samples.md" file

Expected:
  • File content loads in main panel
  • Breadcrumb shows "guide/programming-samples.md"
  • File item in tree is highlighted/active
  • Code blocks are syntax-highlighted
4 Verify IndexedDB Storage

Open Browser DevTools → Application/Storage → IndexedDB → doclight

Expected:
  • Object Store "lastOpened" contains: { key: "file", path: "guide/programming-samples.md", ts: [timestamp] }
  • Object Store "treeState" contains: { path: "guide", expanded: true, ts: [timestamp] }
5 Refresh Page (CRITICAL TEST)

Press F5 or Ctrl+R to refresh the page

Expected AUTO-LOAD BEHAVIOR:
  • ✅ Page loads
  • ✅ File tree renders
  • ✅ "guide" folder is automatically expanded
  • ✅ "programming-samples.md" is automatically loaded
  • ✅ Breadcrumb shows "guide/programming-samples.md"
  • ✅ File item in tree is marked active
  • ✅ Code blocks are rendered and highlighted
  • ✅ Main content shows markdown-rendered file
6 Test Navigation

Click on a different file (e.g., "README.md" at root level)

Expected: README.md loads, IndexedDB updates to new file path
7 Re-test Auto-Load

Refresh page again (F5)

Expected: README.md automatically loads (no folder expansion needed as it's at root)
8 Test Nested Path

Navigate to a file in a nested folder (if available, e.g., "guide/examples/test.md")

Refresh page

Expected: All parent folders automatically expand, nested file loads

🤖 Automated Verification

Run these checks in browser console after Step 5 (refresh):

📊 Verification Checklist

// Console verification script const verifyAutoLoad = () => { const results = { breadcrumb: document.getElementById('breadcrumb').textContent, guideFolderExpanded: false, fileItemExists: false, fileItemActive: false, contentLoaded: false, codeBlocksRendered: false }; // Check guide folder expansion const guideWrapper = document.querySelector('.tree-item-wrapper[data-path="guide"]'); if (guideWrapper) { const childrenDiv = guideWrapper.querySelector('.tree-children'); results.guideFolderExpanded = childrenDiv && childrenDiv.style.display !== 'none'; } // Check file item in tree const fileItem = document.querySelector('.tree-item[data-path="guide/programming-samples.md"]'); results.fileItemExists = fileItem !== null; results.fileItemActive = fileItem && fileItem.classList.contains('active'); // Check content loaded const content = document.querySelector('.markdown-content'); results.contentLoaded = content && content.children.length > 0; results.codeBlocksRendered = document.querySelectorAll('.markdown-content pre code').length > 0; // Display results console.table(results); // Overall pass/fail const allPassed = Object.values(results).every(v => v === true || v.includes('guide/programming-samples.md')); console.log(allPassed ? '✅ ALL CHECKS PASSED' : '❌ SOME CHECKS FAILED'); return results; }; verifyAutoLoad();

🐛 Known Issues & Edge Cases

  • File deleted: If last viewed file no longer exists, should show welcome screen (graceful fallback)
  • Folder renamed: Auto-expand may fail if folder path changed
  • IndexedDB disabled: Feature should degrade gracefully, no errors
  • Slow network: File should still load, just with delay

✅ Success Criteria

Test PASSES if after page refresh:
  1. Breadcrumb = "guide/programming-samples.md"
  2. Guide folder is expanded (visible children)
  3. File item is visible in tree and marked active
  4. Main content shows rendered markdown with code highlighting
  5. No JavaScript errors in console
  6. IndexedDB contains correct lastOpened record
