# Phase 1: resolve_project 도구 구현

## 목적

AI 에이전트가 자연어 프로젝트/라이브러리명으로 문서 경로를 찾을 수 있도록 `resolve_project` MCP 도구를 추가한다. Context7의 `resolve-library-id`에 해당하는 기능.

## 테스트 시나리오

### 정상 케이스

```
Given: 문서 디렉토리에 "00.공통 모듈/jons5/json5.md" 존재
When: resolve_project("json5") 호출
Then: [{ path: "00.공통 모듈/jons5", name: "jons5", score >= 0.7 }] 반환
```

```
Given: 문서 디렉토리에 "00.공통 모듈/OptionWeaver/" 존재
When: resolve_project("옵션위버") 호출 (한글 검색)
Then: frontmatter aliases에 "옵션위버"가 있으면 매칭
```

### 예외 케이스

```
Given: 매칭되는 프로젝트 없음
When: resolve_project("nonexistent-lib") 호출
Then: 빈 배열 반환, 에러 없음
```

```
Given: 빈 문자열 입력
When: resolve_project("") 호출
Then: INVALID_QUERY 에러 반환
```

### 경계값 테스트

```
Given: 유사한 이름의 프로젝트 여러 개 (json5, json4j, jsonlib)
When: resolve_project("json") 호출
Then: 모두 반환, score 순 정렬
```
