# Context7 수준 MCP 개선 — 구현 계획

## 개요

DocLight MCP 서버를 Context7 수준의 AI 에이전트 친화성으로 개선한다.
품질 점수(c7score) 기능은 범위에서 제외.

**프로젝트 규모**: SMALL (요구사항 4개, Phase 4개)
**언어/프레임워크**: Node.js / Express
**기존 코드**: `src/routes/mcp.js`, `src/services/mcp/`

## 비즈니스 목표

| ID | 목표 | 우선순위 |
|----|------|----------|
| BG-001 | AI 에이전트가 자연어로 프로젝트를 찾을 수 있어야 함 | P0 |
| BG-002 | AI 에이전트가 코드 예제를 효율적으로 추출할 수 있어야 함 | P1 |
| BG-003 | 버전별 문서를 구분하여 제공할 수 있어야 함 | P1 |
| BG-004 | AI 에이전트가 DocLight를 자동으로 활용하도록 안내해야 함 | P2 |

## Phase 구조

| Phase | 제목 | 의존성 | 신규 파일 | 수정 파일 |
|-------|------|--------|----------|----------|
| [Phase 1](01.phase-1-resolve-project.md) | resolve_project 도구 | 없음 | project-resolver-service.js | mcp.js, context-mcp.js, app.js |
| [Phase 2](02.phase-2-code-examples.md) | query_code_examples 도구 | Phase 1 | code-block-extractor.js | mcp.js |
| [Phase 3](03.phase-3-version-docs.md) | 버전별 문서 지원 | Phase 1 | 없음 | project-resolver-service.js |
| [Phase 4](04.phase-4-auto-invocation.md) | 자동 호출 메커니즘 | Phase 1 | 없음 | mcp.js, context-mcp.js |

## 의존성 그래프

```
Phase 1 (resolve_project)
  ├──→ Phase 2 (query_code_examples)
  ├──→ Phase 3 (버전별 문서)
  └──→ Phase 4 (자동 호출)
```

Phase 2, 3, 4는 Phase 1 완료 후 **병렬 실행 가능**.
