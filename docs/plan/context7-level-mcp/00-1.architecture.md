## 2. 신규 컴포넌트

### 2.1 ProjectResolverService

**역할**: 자연어 프로젝트/라이브러리명을 문서 경로로 매핑

```
입력: "json5", "옵션위버", "AnnotaQL"
출력: [{ path: "/00.공통 모듈/jons5", name: "jons5", score: 0.95, docs: 1 }]
```

**매칭 전략** (우선순위순):
1. 디렉토리명 정확 일치
2. 디렉토리명 대소문자 무시 일치
3. frontmatter `aliases` 필드 매칭
4. 문서 제목(H1) 매칭
5. 디렉토리명/파일명 퍼지 매칭 (포함, 편집 거리)

**데이터 구조**:
```javascript
// ProjectIndex (메모리 캐시, 서버 시작 시 구축)
{
  entries: [
    {
      path: "/00.공통 모듈/jons5",
      dirName: "jons5",
      aliases: ["json5", "jons5"],    // frontmatter에서 추출
      title: "JSON5 Library Guide",   // 첫 번째 .md 파일의 H1
      description: "JSON5 Java 라이브러리 문서",
      docCount: 1,
      versions: []                     // Phase 2에서 활용
    }
  ]
}
```

### 2.2 CodeBlockExtractorService

**역할**: 문서에서 코드 블록만 추출하여 반환

```
입력: query="comment 작성 방법", language="java", path="/"
출력: [{ path, heading, language, code, context, score }]
```

**추출 알고리즘**:
1. 마크다운에서 fenced code block (```) 파싱
2. 언어 태그 필터링 (java, python, javascript 등)
3. 코드 블록 직전 헤딩/설명 텍스트를 context로 보존
4. query 키워드와 코드+context 매칭하여 점수 산출
5. 토큰 예산 내에서 상위 결과 반환

### 2.3 VersionResolver (Phase 2 구조 준비)

**역할**: 버전별 문서 경로 해석

**디렉토리 컨벤션**:
```
/projects/library-name/
  v1.0/
    guide.md
  v2.0/
    guide.md
  latest -> v2.0  (심볼릭 또는 frontmatter)
```

**frontmatter 컨벤션**:
```yaml
---
version: "2.0.0"
library: "jons5"
---
```

## 4. 데이터 흐름

### resolve_project → query_document 워크플로우

```
Agent: resolve_project("json5")
  → ProjectResolverService.resolve("json5")
    → 인덱스 퍼지 매칭
    → [{ path: "00.공통 모듈/jons5", score: 0.95 }]

Agent: query_document("00.공통 모듈/jons5/json5.md", "comment 작성")
  → QueryDocumentService.queryDocument()
    → SectionExtractor로 관련 섹션 추출
    → 토큰 예산 내 결과 반환
```

### resolve_project → query_code_examples 워크플로우

```
Agent: resolve_project("json5")
  → [{ path: "00.공통 모듈/jons5" }]

Agent: query_code_examples("00.공통 모듈/jons5", "annotation 사용법", "java")
  → CodeBlockExtractorService.extract()
    → 코드 블록 파싱 + 언어 필터 + 쿼리 매칭
    → [{ code: "...", context: "## @JSON5Type - Class Annotation", score: 0.89 }]
```
