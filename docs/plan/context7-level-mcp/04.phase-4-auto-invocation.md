# Phase 4: 자동 호출 메커니즘

## 목적

AI 에이전트가 DocLight MCP를 자동으로 활용하도록 서버 인스트럭션과 가이드를 구성한다. Context7의 "use context7" 자동 트리거에 해당.

## 선행 조건

- Phase 1 완료 (resolve_project 도구가 존재해야 가이드 작성 가능)

## 아키텍처 참조

- `00-2.tech-decisions.md` § ADR-005

## 구현 체크리스트

### 4.1 MCP serverInstructions 추가

- [ ] `src/routes/mcp.js` — `initialize` 응답에 `instructions` 필드 추가

```javascript
case 'initialize':
  return res.json(createJsonRpcResponse(id, {
    protocolVersion: '2024-11-05',
    capabilities: { tools: {} },
    serverInfo: {
      name: 'DocuLight',
      version: '1.0.0'
    },
    instructions: `Use this server to retrieve internal documentation and code examples.

Recommended workflow:
1. Call resolve_project to find the right document path for a project/library
2. Call query_document or query_code_examples with the resolved path
3. Use DocuLight_smart_search for cross-document natural language search
4. Use summarize_document to understand document structure before reading

Tips:
- Always resolve_project first if you don't know the exact path
- Use query_code_examples when you need code examples specifically
- Set maxTokens to control response size`
  }));
```

### 4.2 Context MCP 라우터에도 instructions 추가

- [ ] `src/routes/context-mcp.js` — `initialize` 응답에 동일 구조 추가

### 4.3 도구 설명 최적화

- [ ] 각 도구의 `description`이 AI 에이전트에게 명확한 사용 시점을 안내하는지 검토
- [ ] `resolve_project`: "Use this **before** other tools when you know the project name but not the path"
- [ ] `query_code_examples`: "Use this when you need **code examples specifically**, not full documentation"
- [ ] `DocuLight_smart_search`: "Use this for **cross-document** natural language search"

### 4.4 .claude.json MCP 서버 설명 추가

- [ ] context0 MCP 서버 설정에 description/instructions 필드가 있으면 활용
- [ ] Claude Code가 MCP 서버 목적을 이해할 수 있는 메타데이터 제공

## 테스트 시나리오

### 정상 케이스

```
Given: AI 에이전트가 MCP initialize 호출
When: 서버 응답 수신
Then: instructions 필드에 워크플로우 가이드 포함
```

```
Given: AI 에이전트가 tools/list 호출
When: 도구 목록 수신
Then: 각 도구 description에 사용 시점이 명확히 기술됨
```

### 경계값 테스트

```
Given: 기존 MCP 클라이언트가 instructions 필드를 무시
When: initialize 호출
Then: 기존 필드(protocolVersion, capabilities 등)는 변경 없음 → 하위 호환
```

- [ ] 워크플로우 가이드가 명확하고 실용적
- [ ] 도구 설명이 AI 에이전트 친화적으로 개선
- [ ] 기존 MCP 클라이언트와 하위 호환
