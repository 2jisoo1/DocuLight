# Phase 2: query_code_examples 도구 구현

## 목적

문서에서 코드 블록만 추출하여 AI 에이전트에게 제공하는 `query_code_examples` MCP 도구를 추가한다. Context7이 코드 스니펫을 우선 제공하는 것과 동등한 기능.

## 선행 조건

- Phase 1 완료 (resolve_project로 경로 확보 후 사용하는 워크플로우)

## 아키텍처 참조

- `00-1.architecture.md` § 2.2 CodeBlockExtractorService
- `00-2.tech-decisions.md` § ADR-003

## 구현 체크리스트

### 2.1 CodeBlockExtractorService 클래스 생성

- [ ] `src/services/mcp/code-block-extractor.js` 생성
- [ ] `parseCodeBlocks(content)` — fenced code block 파싱
  - 언어 태그 추출 (```java, ```python 등)
  - 코드 내용 추출
  - 직전 헤딩 + 설명 텍스트를 context로 캡처
  - 라인 번호 기록
- [ ] `extract(query, options)` — 쿼리 기반 코드 블록 검색
  - `path` — 검색 디렉토리 (기본: /)
  - `language` — 언어 필터 (선택)
  - `maxTokens` — 토큰 예산 (기본: 3000)
  - `limit` — 최대 결과 수 (기본: 10)
- [ ] `scoreCodeBlock(block, query)` — 관련성 점수 계산
  - 코드 내 쿼리 키워드 존재: +0.3
  - context(헤딩/설명)에 키워드 존재: +0.4
  - 코드 블록 크기 보너스 (적당한 길이 선호): +0.2
  - 언어 매칭: +0.1
- [ ] `formatAsMarkdown(results)` — 결과 마크다운 포맷

- [ ] 중첩 코드 블록 처리 (드물지만 안전하게)

{

## 테스트 시나리오

### 정상 케이스

```
Given: json5.md에 java 코드 블록 10개 존재
When: query_code_examples("annotation 사용법", language="java", path="00.공통 모듈/jons5")
Then: @JSON5Type, @JSON5Value 관련 코드 블록이 score 순으로 반환
```

```
Given: 여러 문서에 코드 블록 분포
When: query_code_examples("configuration", path="/")
Then: 모든 문서에서 관련 코드 블록 수집, score 순 정렬
```

### 예외 케이스

```
Given: 코드 블록이 없는 문서
When: query_code_examples("setup")
Then: 빈 결과 반환, 에러 없음
```

```
Given: 존재하지 않는 언어 필터
When: query_code_examples("test", language="brainfuck")
Then: 빈 결과 반환, 에러 없음
```

### 경계값 테스트

```
Given: 매우 긴 코드 블록 (500줄)
When: query_code_examples("example", maxTokens=500)
Then: 코드 블록이 토큰 예산 내로 잘려서 반환, truncated 표시
```
