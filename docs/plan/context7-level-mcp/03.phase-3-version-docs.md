# Phase 3: 버전별 문서 지원

## 목적

프로젝트 문서를 버전별로 관리하고, `resolve_project`에서 버전 목록을 반환하며, 특정 버전의 문서를 조회할 수 있도록 한다. Context7의 `/org/project/version` 패턴에 해당.

## 선행 조건

- Phase 1 완료 (resolve_project 도구)

## 아키텍처 참조

- `00-1.architecture.md` § 2.3 VersionResolver
- `00-2.tech-decisions.md` § ADR-004

## 구현 체크리스트

### 3.1 버전 감지 로직 추가

- [ ] `project-resolver-service.js`에 버전 감지 추가
- [ ] 디렉토리명 패턴 매칭: `/v\d+(\.\d+)*/`, `/\d+\.\d+/`
- [ ] frontmatter `version` 필드 읽기
- [ ] 버전 목록을 `resolve_project` 결과에 포함

```javascript
// resolve_project 결과 확장
{
  path: "00.공통 모듈/jons5",
  name: "jons5",
  score: 0.95,
  docCount: 3,
  versions: [
    { version: "1.0", path: "00.공통 모듈/jons5/v1.0" },
    { version: "2.0", path: "00.공통 모듈/jons5/v2.0" }
  ],
  latestVersion: "2.0"
}
```

### 3.2 버전별 경로 해석

- [ ] `resolve_project("json5 v2.0")` — 버전 지정 시 해당 버전 경로 반환
- [ ] 쿼리에서 버전 패턴 분리: `parseVersionFromQuery(query)`

```javascript
// "json5 v2.0" → { name: "json5", version: "2.0" }
// "json5"      → { name: "json5", version: null }  // latest
```

### 3.3 MCP 도구 스키마 확장

- [ ] `resolve_project` inputSchema에 `version` 파라미터 추가 (선택)

```javascript
version: {
  type: 'string',
  description: 'Specific version to resolve (e.g., "2.0"). If omitted, returns all versions.'
}
```

### 3.4 latest 버전 판별

- [ ] semver 정렬로 최신 버전 자동 판별
- [ ] frontmatter `latest: true` 명시 지원
- [ ] 버전 디렉토리가 없으면 프로젝트 루트가 곧 최신

### 3.5 기존 도구 호환

- [ ] `query_document`, `read_document` 등은 경로 기반이므로 변경 불필요
- [ ] `resolve_project`가 버전별 경로를 반환하면 에이전트가 해당 경로로 호출

## 테스트 시나리오

### 정상 케이스

```
Given: /projects/mylib/v1.0/ 와 /projects/mylib/v2.0/ 존재
When: resolve_project("mylib")
Then: versions: [{ version: "1.0", ... }, { version: "2.0", ... }], latestVersion: "2.0"
```

```
Given: 위와 동일
When: resolve_project("mylib", version="1.0")
Then: path가 v1.0 디렉토리를 가리킴
```

### 예외 케이스

```
Given: 버전 디렉토리 없는 프로젝트
When: resolve_project("simple-project")
Then: versions: [], latestVersion: null (정상 동작, 에러 없음)
```

### 경계값 테스트

```
Given: frontmatter version과 디렉토리명 버전이 다른 경우
When: resolve_project("lib")
Then: 디렉토리명 우선 (ADR-004)
```

## 완료 기준

- [ ] 버전 디렉토리 자동 감지
- [ ] frontmatter `version` 필드 인식
- [ ] `resolve_project` 결과에 versions 배열 포함
- [ ] 특정 버전 지정 검색 동작
- [ ] 버전 없는 프로젝트도 정상 동작 (하위 호환)
- [ ] 기존 도구 회귀 없음
