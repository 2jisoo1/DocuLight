### 1.3 base-json-store.js 구현

- [ ] `src/stores/base-json-store.js` 생성

### 1.4 group-store.js 구현

- [ ] `src/stores/group-store.js` 생성 (base-json-store 상속/위임)
- [ ] `initialize()`: groups.json 로드. 없으면 기본 3개 그룹 생성 (Superuser, Editor, Viewer)
- [ ] `findAll()`: 전체 그룹 목록 반환
- [ ] `findById(id)`: ID로 그룹 조회
- [ ] `findByName(name)`: 이름으로 그룹 조회

- [ ] `update(id, updates)`: 그룹 수정 (시스템 그룹 권한 변경 불가)
- [ ] `delete(id)`: 그룹 삭제 (시스템 그룹 불가, 소속 사용자 0명 검사)
- [ ] `getMemberCount(groupId)`: 소속 사용자 수 반환 (UserStore 참조)
- [ ] 검증: CRUD 동작 + 시스템 그룹 보호 + 중복 이름 방지

### 1.5 user-store.js 구현

- [ ] `src/stores/user-store.js` 생성
- [ ] `initialize()`: users.json 로드 → `emailIndex`, `userKeyIndex`, `idIndex` 구축
- [ ] `getUserCount()`: 전체 사용자 수 반환 (Setup Wizard 판단용)
- [ ] `findByEmail(email)`: 이메일 인덱스로 O(1) 조회 (소문자 정규화)
- [ ] `findByUserKeyHash(hash)`: user-key 해시 인덱스로 O(1) 조회
- [ ] `findById(id)`: ID 인덱스로 O(1) 조회
- [ ] `findAll()`: 전체 사용자 목록 반환 (패스워드 해시/키 해시 제외)
- [ ] `create(userData)`: 사용자 생성 (UUID, 이메일 중복 검사, bcrypt 해시, user-key 생성)
  - 반환: `{ user, userKey }` (userKey 원본은 이때만 반환)
- [ ] `update(id, updates)`: 사용자 수정 (인덱스 갱신)
- [ ] `delete(id)`: 사용자 삭제 (인덱스 갱신)
- [ ] `updatePassword(id, newPasswordHash)`: 패스워드 변경
- [ ] `regenerateUserKey(id)`: user-key 재발급 → 새 키의 SHA-256 해시 저장, 인덱스 갱신
  - 반환: `{ userKey }` (원본)
- [ ] `incrementFailedLogin(id)`: 로그인 실패 카운터 증가 + 5회 시 잠금
- [ ] `resetFailedLogin(id)`: 카운터 리셋 + 잠금 해제
- [ ] `updateLastLogin(id)`: 마지막 로그인 시각 갱신
- [ ] `getSuperuserCount()`: 슈퍼유저 그룹 소속 활성 사용자 수
- [ ] 검증: CRUD + 인덱스 일관성 + 마지막 슈퍼유저 보호

## 테스트 시나리오

### 정상 케이스

**Given**: data 디렉토리가 비어있는 상태
**When**: `UserStore.initialize()` 호출 후 `UserStore.getUserCount()` 호출
**Then**: 0 반환

**Given**: 사용자 1명 생성 완료
**When**: `UserStore.findByEmail("admin@test.com")` 호출
**Then**: 해당 사용자 객체 반환

### 예외 케이스

**Given**: users.json이 손상된 JSON
**When**: `UserStore.initialize()` 호출
**Then**: 파싱 에러 throw (서버 시작 실패)

**Given**: 이미 존재하는 이메일
**When**: 동일 이메일로 `UserStore.create()` 호출
**Then**: `EMAIL_DUPLICATE` 에러 throw

### 경계값 테스트

**Given**: 사용자 1,000명이 등록된 상태
**When**: `UserStore.findByUserKeyHash(hash)` 호출
**Then**: O(1) 조회 성공 (Map 인덱스)
