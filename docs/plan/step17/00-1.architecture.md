## 5. 권한 계층

```
superuser ──────► write ──────► read
  │                │              │
  │ 사용자/그룹     │ 문서 생성    │ 문서 열람
  │ 관리           │ 수정/삭제    │
  │ 인증 설정      │ 업로드       │
  │ 가입 승인/거절  │             │
```

**권한 검사 로직**:
```javascript
function hasPermission(userPermissions, required) {
  if (userPermissions.includes('superuser')) return true;
  if (required === 'write' && userPermissions.includes('write')) return true;
  if (required === 'read' && (userPermissions.includes('read') || userPermissions.includes('write'))) return true;
  // 기존 'delete' 요청은 'write'로 매핑
  if (required === 'delete' && userPermissions.includes('write')) return true;
  return false;
}
```

## 6. In-Memory 캐시 구조

```javascript
// UserStore 내부
class UserStore {
  constructor() {
    this.users = [];                    // 전체 사용자 배열
    this.emailIndex = new Map();        // Map<email, userId>
    this.userKeyIndex = new Map();      // Map<sha256(userKey), userId>
    this.idIndex = new Map();           // Map<userId, userObject>
  }
}
```

- 서버 시작 시 파일에서 전체 로드 → Map 인덱스 구축
- CRUD 작업 시 파일 쓰기 + Map 인덱스 동기 갱신
- 단일 프로세스 제약 (PM2 fork mode만 지원)
