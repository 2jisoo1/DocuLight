# Phase 5: 인증 설정 관리 (Admin UI)

## 목표

슈퍼유저가 /admin UI에서 인증 관련 설정(읽기 로그인, 세션 타임아웃, 가입 허용, 이메일 도메인 제한)을 변경할 수 있게 한다.

## 선행 조건

- Phase 4 완료 (사용자/그룹 관리 API + UI)

## 아키텍처 참조

- SRS FR-17-009: 인증 설정 관리

## 구현 체크리스트

### 5.1 인증 설정 API

- [ ] `src/controllers/admin/admin-auth-settings-controller.js` 생성
- [ ] `GET /api/admin/auth-settings` — 현재 인증 설정 조회
  - 슈퍼유저 전용
  - 응답: `{ success: true, settings: {...} }`
- [ ] `PUT /api/admin/auth-settings` — 인증 설정 변경
  - 슈퍼유저 전용
  - body: `{ requireReadLogin?, sessionTimeout?, allowSignup?, allowedEmailDomains? }`
  - 검증:
    - `sessionTimeout` ≥ 60000ms
    - `allowedEmailDomains`는 문자열 배열
  - `AuthSettingsStore.update(settings, req.adminSession.userId)`
  - 변경 즉시 적용 (in-memory 설정 갱신)
- [ ] `admin-api.js`에 라우트 등록
- [ ] 검증: 설정 조회 + 변경 + 즉시 반영

### 5.2 설정 변경 즉시 반영 메커니즘

- [ ] `AuthSettingsStore`가 `update()` 호출 시 in-memory 캐시 갱신
- [ ] 미들웨어에서 `AuthSettingsStore.get()`으로 현재 설정 읽기 (매 요청마다)
- [ ] `requireReadLogin` 변경 시: 다음 요청부터 즉시 적용
- [ ] `sessionTimeout` 변경 시: 새로 생성되는 세션부터 적용 (기존 세션 유지)
- [ ] 검증: 설정 변경 후 다음 요청에서 즉시 반영 확인

### 5.3 Admin UI — 인증 설정 탭

- [ ] `public/js/admin.js`에 인증 설정 탭 UI 추가
  - **읽기 로그인 (requireReadLogin)**: 토글 스위치
    - 활성화 시 경고: "모든 접근에 인증이 필요합니다"
  - **세션 타임아웃 (sessionTimeout)**: 숫자 입력 (분 단위 UI, ms 변환)
    - 최소 1분, 기본 60분
  - **가입 요청 허용 (allowSignup)**: 토글 스위치
    - 비활성화 시 안내: "가입 요청 기능이 꺼집니다"
  - **허용 이메일 도메인 (allowedEmailDomains)**: 태그 입력
    - 빈 배열 = 모든 도메인 허용
    - 예: `company.com`, `partner.co.kr`
  - "저장" 버튼 → PUT /api/admin/auth-settings
  - 성공/실패 토스트 메시지
- [ ] 검증: 각 설정 항목 변경 + 저장 + 즉시 반영

## 테스트 시나리오

### 정상 케이스

**Given**: 슈퍼유저로 /admin 인증 설정 탭 접근
**When**: requireReadLogin을 false → true로 변경 후 저장
**Then**: 저장 성공, 즉시 미인증 GET /api/tree가 401 반환

**Given**: sessionTimeout을 30분(1800000ms)으로 변경
**When**: 새로 로그인
**Then**: 새 세션의 만료 시간이 30분으로 설정됨

### 예외 케이스

**Given**: sessionTimeout에 0 입력
**When**: 저장 시도
**Then**: 400 `INVALID_SETTING_VALUE` (최소 60000ms)

**Given**: Editor 사용자로 로그인
**When**: GET /api/admin/auth-settings 접근
**Then**: 403 (슈퍼유저 전용)

### 경계값 테스트

**Given**: allowedEmailDomains에 `[""]` (빈 문자열) 포함
**When**: 저장 시도
**Then**: 빈 문자열 필터링 후 저장 (또는 400 에러)
