# Phase 6 검증 보고서

## 완료 체크리스트

### 6.1 내 정보 API
- [ ] `auth-controller.js`에 `GET /api/auth/me` 추가
- [ ] 로그인 필수 (세션 기반)
- [ ] 응답: id, email, groupName, permissions, lastLoginAt, userKey (마스킹)
- [ ] 검증: 로그인 사용자의 정보 조회 성공

### 6.2 user-key 전체 조회
- [ ] user-key 원본은 서버에 저장되지 않음 (SHA-256 해시만 저장)
- [ ] "보기" 기능은 재발급 시에만 원본 제공
- [ ] UI에서 마스킹된 키만 표시
- [ ] 검증: 마스킹 표시 동작

### 6.3 패스워드 변경 API
- [ ] `PUT /api/auth/me/password` 구현
- [ ] 현재 패스워드 확인, 새 패스워드 강도 검증, 일치 검증
- [ ] bcrypt 해시 저장, 기존 세션 유지
- [ ] 검증: 패스워드 변경 후 기존 세션으로 계속 사용 가능

### 6.4 user-key 재발급 API
- [ ] `POST /api/auth/me/regenerate-key` 구현
- [ ] 새 key SHA-256 해시 저장, 인덱스 갱신
- [ ] 응답에서만 원본 키 제공
- [ ] 검증: 재발급 후 기존 key 무효, 새 key 유효

### 6.5 Admin UI -- 내 정보 탭/메뉴
- [ ] 모든 권한 사용자에게 표시
- [ ] 정보 표시: 이메일, 소속 그룹명, 권한, 마지막 로그인
- [ ] user-key 영역: 마스킹 표시 + "재발급" 버튼 + 복사 버튼
- [ ] 패스워드 변경 영역: 현재/새/확인 입력 + "변경" 버튼
- [ ] 검증: 내 정보 조회, 패스워드 변경, user-key 재발급 UI 동작
