## Phase 개요

| Phase | 제목 | 우선순위 | 의존성 | 핵심 산출물 |
|-------|------|---------|--------|------------|
| [Phase 1](01.phase-1-data-layer.md) | 데이터 계층 + 파일 저장소 서비스 | P0 | 없음 | UserStore, GroupStore, AuthSettingsStore |
| [Phase 2](02.phase-2-auth-core.md) | 최초 설정 마법사 + 로그인/로그아웃 | P0 | Phase 1 | SetupWizard, AuthController, 세션 확장 |
| [Phase 3](03.phase-3-middleware-transition.md) | 인증 미들웨어 전환 | P0 | Phase 2 | auth.js, admin-auth.js, mcp.js 전환 |
| [Phase 4](04.phase-4-admin-crud.md) | 그룹/사용자 CRUD (Admin API + UI) | P0 | Phase 3 | 사용자/그룹 관리 API + Admin UI 탭 |
| [Phase 5](05.phase-5-auth-settings-ui.md) | 인증 설정 관리 (Admin UI) | P0 | Phase 4 | auth-settings API + UI 탭 |
| [Phase 6](06.phase-6-my-profile.md) | 내 정보 페이지 + user-key 관리 | P1 | Phase 3 | 내 정보 API + UI |

| [Phase 8](08.phase-8-security-hardening.md) | Rate Limiting + 보안 강화 | P1 | Phase 7 | express-rate-limit, 보안 체크리스트 |
| [Phase 9](09.phase-9-migration-compat.md) | 하위 호환성 + 마이그레이션 | P2 | Phase 8 | apiKey 마이그레이션, CLI 리셋 도구 |

## 의존성 그래프

```
Phase 1 (데이터 계층)
  └─► Phase 2 (설정 마법사 + 로그인)
       └─► Phase 3 (미들웨어 전환)
            ├─► Phase 4 (사용자/그룹 CRUD)
            │    └─► Phase 5 (인증 설정 UI)
            │         └─► Phase 7 (가입 + 이메일)
            └─► Phase 6 (내 정보)
                 └─► Phase 7 (가입 + 이메일)
                      └─► Phase 8 (보안 강화)
                           └─► Phase 9 (마이그레이션)
```
