# Getting Started

Welcome to DocLight! This guide will help you get started quickly.

## Installation

To install DocLight, run the following command:

```bash
npm install doclight
```

## Configuration

Create a configuration file called `config.json5`:

```json5
{
  docsRoot: "./docs",
  port: 3000
}
```

## Authentication

DocLight supports API key authentication for protected endpoints.

Set your API key in the configuration:

```json5
{
  apiKey: "your-secret-key"
}
```

## Next Steps

Check out the API documentation for more details.
